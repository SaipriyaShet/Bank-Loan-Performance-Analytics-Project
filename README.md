# Bank-Loan-Performance-Analytics-Project
This project involves analyzing a bank loan dataset to uncover insights about loan approvals, customer demographics, and potential risk factors.   The goal is to perform exploratory data analysis (EDA), create meaningful  visualizations, and build dashboards that can help banks make data-driven decisions
